# Getting Support for RPX

Thank you for using **RPX (Repository Project Explorer)**. Here is how to find help, ask questions, and report issues.

---

## 1. Documentation & Architecture

Before opening an issue, check the bundled documentation:

- [README.md](README.md) — Quick start, CLI command reference, and configuration flags.
- [ARCHITECTURE.md](ARCHITECTURE.md) — Technical overview of analyzers, models, and reporters.
- [CONTRIBUTING.md](CONTRIBUTING.md) — Local development and contribution guidelines.

---

## 2. Asking Usage Questions

If you have questions about how to use RPX, configure custom weights, or integrate it into your workflow:

- Check existing [GitHub Issues](https://github.com/VinitSurve/rpx/issues) to see if your question has been addressed.
- Open an issue labeled `question` or participate in repository discussions.

---

## 3. Reporting Bugs

If you find a defect, crash, incorrect metric, or unexpected CLI behavior:

1. Search existing issues to verify it has not already been reported.
2. File a new issue using our [Bug Report Form](https://github.com/VinitSurve/rpx/issues/new?template=bug_report.yml).
3. Include your operating system, Python version, RPX version (`rpx --version`), and steps to reproduce.

---

## 4. Proposing Features

Have an idea for a new language parser, dependency analyzer, or export format?

- Submit a proposal using the [Feature Request Form](https://github.com/VinitSurve/rpx/issues/new?template=feature_request.yml).
- Describe the motivation, intended behavior, and potential CLI commands or flags.

---

## 5. Security Vulnerabilities

Please **do not** open public issues for security vulnerabilities or secret leaks.

Refer to our [Security Policy](SECURITY.md) and report vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/VinitSurve/rpx/security/advisories/new).

---

## 6. Support Expectations

RPX is maintained as an open-source developer tool. Issues and pull requests are triaged on a best-effort basis by the maintainers. While we strive to address defects promptly, we cannot offer guaranteed SLA or real-time support.

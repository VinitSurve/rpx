# Changelog

All notable changes to the **RPX (Repository Project Explorer)** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-09

### Added
- Initial production release of RPX (Repository Project Explorer).
- Fast filesystem scanner with built-in exclusion rules, `.gitignore`, and `.rpxignore` support.
- Accurate language-aware Lines of Code (LOC) counter supporting 40+ programming and markup languages.
- Language distribution analysis with horizontal graphical bar charts.
- Multi-ecosystem dependency and lockfile analyzer (Python, Node/TS, Rust, Go, PHP, Ruby, Java/Kotlin, .NET, Dart, Swift).
- Full local Git analytics engine (commits, branches, contributors, status, timeline activity).
- Heuristic project health and code quality indicators with transparent scoring (0-100).
- Project directory tree explorer with customizable depth, size annotations, and file counts.
- Storage analytics categorized by source, documentation, configuration, and assets.
- Visual Rich terminal dashboard with custom color themes, panels, tables, and progress indicators.
- JSON and CSV structured export systems with schema versioning.
- Configuration file management (`rpx config init`, `rpx config show`).
- Global packaging and `pipx` installation support on macOS.
